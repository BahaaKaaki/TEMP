# Investment / portfolio strategy

## When to use this skill
Use for portfolio review, investment priorities, sovereign / holding portfolio direction, capital allocation, thematic investment strategy, or prioritizing opportunities across sectors or assets. Do not use for a single-asset business case unless portfolio choices are not in scope.

## Executive summary
**One page only.**  
It should track the full deck and usually contain 3–5 components such as portfolio baseline, investment thesis, priority choices, allocation logic, and execution direction.

## Typical output
Typical length: 10–16 pages in a standard version. This is the default for a broad ask; narrower requests may cover only one section or page, while deeper asks may extend the deck.

### 0) Executive summary — 1 page
**What it is:** One-page storyline tracker for the portfolio deck  
**What it includes:** investment answer, 3–5 messages, value implication, execution direction  
**Typical formats:** message page; pillar summary; investment thesis page

### 1) Portfolio baseline — 1–3 pages
**What it is:** Current portfolio position and performance  
**What it includes:** holdings, allocation, performance, concentration, gaps  
**Typical formats:** portfolio view; performance summary; heatmap

### 2) Market and capital context — 1–3 pages
**What it is:** External context that should shape allocation  
**What it includes:** market outlook, themes, value pools, risk / return context  
**Typical formats:** benchmark table; trend summary; market map

### 3) Investment thesis and choices — 1–3 pages
**What it is:** Where capital should be directed  
**What it includes:** priority sectors, themes, assets, archetypes, trade-offs  
**Typical formats:** 2x2; option screen; portfolio matrix

### 4) Allocation logic and opportunities — 2–4 pages
**What it is:** How capital will be allocated and through what opportunities  
**What it includes:** criteria, target allocation, pipeline, deal types, platform plays  
**Typical formats:** allocation table; bubble chart; opportunity portfolio

### 5) Value creation and governance — 1–2 pages
**What it is:** How investments will create value and be governed  
**What it includes:** value-creation model, ownership, decision rights, monitoring  
**Typical formats:** governance chart; value bridge; scorecard

### 6) Roadmap and implementation — 1–2 pages
**What it is:** How the strategy will be operationalized  
**What it includes:** sequencing, milestones, capability needs, next decisions  
**Typical formats:** roadmap; phased plan; chevron with sub-steps

### 7) KPIs and review logic — 1–2 pages
**What it is:** How success will be tracked  
**What it includes:** portfolio KPIs, review cadence, escalation  
**Typical formats:** KPI scorecard; governance chart; cadence view

## How to build
- define the investment objective and role of the portfolio
- baseline the portfolio and current allocation logic
- bring in the market, thematic, and capital context
- define investment thesis and priority choices
- translate into allocation logic, opportunity pipeline, and governance

## Typical data needed
portfolio holdings and performance; investment mandate; market and sector outlook; risk / return parameters; funding needs; deal or opportunity pipeline; strategic priorities; governance constraints

## Success criteria
Investment thesis is explicit; choices are prioritized; allocation logic is visible; governance is clear; portfolio role is linked to strategy.

## Common failure modes
Portfolio summary without strategy; no investment criteria; too many priority areas; no resource allocation logic; no governance or monitoring.
