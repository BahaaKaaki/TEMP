# Stakeholder communication planning

## When to use this skill
Use when the main need is a structured communication plan across audiences, moments, and channels. Do not use when the broader problem is full stakeholder management or change design across complex influence dynamics.

## Executive summary
**One page only.**  
It should track the full deck and usually contain 3–5 components such as communication objective, target audiences, message architecture, channel plan, and implementation direction.

## Typical output
Typical length: 6–12 pages in a standard version. This is the default for a broad ask; narrower requests may cover only one section or page, while deeper asks may extend the deck.

### 0) Executive summary — 1 page
**What it is:** One-page storyline tracker for the communication deck  
**What it includes:** communication answer, 3–5 messages, audience implication, execution direction  
**Typical formats:** message page; communication framework; campaign summary

### 1) Communication objective and context — 1–2 pages
**What it is:** Why communication is needed and what it must achieve  
**What it includes:** initiative context, communication objectives, critical moments  
**Typical formats:** context page; issue tree; communication framework

### 2) Audience segmentation — 1–2 pages
**What it is:** Who needs what kind of communication  
**What it includes:** audience groups, needs, sensitivities, role in the initiative  
**Typical formats:** segmentation table; persona view; audience map

### 3) Message architecture — 1–2 pages
**What it is:** What will be communicated and how it differs by audience  
**What it includes:** core messages, tailoring logic, message hierarchy  
**Typical formats:** message house; message map; narrative ladder

### 4) Channel and content strategy — 1–2 pages
**What it is:** How messages will be delivered  
**What it includes:** channels, formats, content types, campaign or event logic  
**Typical formats:** channel matrix; content plan; campaign map

### 5) Communication calendar and cadence — 1–2 pages
**What it is:** When communications will happen  
**What it includes:** cadence, milestones, sequencing, recurring moments  
**Typical formats:** calendar view; roadmap; cadence chart

### 6) Governance and approvals — 1–2 pages
**What it is:** Who owns what and how sign-off works  
**What it includes:** roles, approval flow, escalation, coordination with initiative governance  
**Typical formats:** RACI; approval flow; governance chart

### 7) KPI and feedback loop — 1–2 pages
**What it is:** How communication effectiveness will be monitored  
**What it includes:** engagement metrics, feedback channels, review rhythm  
**Typical formats:** KPI scorecard; dashboard; feedback loop

## How to build
- clarify the communication objective and the audience decisions or behaviors to influence
- segment audiences and define what each group needs to hear
- build a message architecture and channel strategy
- define cadence, campaign moments, approvals, and ownership
- close with a communications calendar and feedback loop

## Success criteria
Messages are audience-specific, channels are chosen intentionally, cadence supports the initiative, and governance is clear enough to run the communication plan day to day.

## Common failure modes
One message for everyone; over-reliance on email; unclear ownership; no approvals; communication calendar disconnected from project milestones.
