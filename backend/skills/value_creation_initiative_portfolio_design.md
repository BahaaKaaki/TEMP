# Value creation / initiative portfolio design

## When to use this skill
Use when the ask is to turn a strategy, transformation, or investment thesis into a prioritized initiative portfolio with quantified impact. Typical asks include value creation plans, synergy plans, transformation initiative portfolios, strategic program design, and post-strategy mobilization. Do not use for a top-level strategy deck that is not yet ready to translate into initiatives.

## Executive summary
**One page only.**  
It should track the full deck and usually contain 3–5 components such as the value ambition, key levers, prioritized portfolio, value bridge, and execution path.

## Typical output
Typical length: 8–14 pages in a standard version. This is the default structure for a broad ask; narrower requests may cover only one section or page, while deeper asks may extend the deck.

### 0) Executive summary — 1 page
**What it is:** One-page storyline tracker for the value-creation deck  
**What it includes:** value ambition, key levers, portfolio choice, value implication, roadmap  
**Typical formats:** message page; value creation summary; portfolio page

### 1) Value ambition and gap — 1–2 pages
**What it is:** What value needs to be created and against what baseline  
**What it includes:** baseline, ambition, gap, timing, key constraints  
**Typical formats:** value bridge; ambition page; baseline snapshot

### 2) Value levers and themes — 1–2 pages
**What it is:** Where the value will come from  
**What it includes:** revenue, margin, cost, capital, productivity, or strategic levers grouped into themes  
**Typical formats:** value lever tree; pillar page; theme map

### 3) Initiative longlist and design principles — 1–2 pages
**What it is:** What the portfolio could include before prioritization  
**What it includes:** initiative universe, boundaries, design principles, linkage to themes  
**Typical formats:** initiative tree; longlist table; design-principles page

### 4) Prioritization and portfolio choices — 1–3 pages
**What it is:** How the portfolio is narrowed to the few moves that matter  
**What it includes:** prioritization criteria, quick wins vs structural moves, selected portfolio  
**Typical formats:** prioritization 2x2; portfolio heatmap; scorecard

### 5) Initiative portfolio and charters — 1–3 pages
**What it is:** What the selected initiatives look like in practice  
**What it includes:** initiative cards, owners, milestones, interdependencies, prerequisites  
**Typical formats:** initiative cards; charter page; swimlane view

### 6) Value bridge and phasing — 1–2 pages
**What it is:** How value lands over time  
**What it includes:** value by initiative, ramp-up, run-rate timing, one-offs, sequence  
**Typical formats:** savings or value waterfall; wave chart; phased bridge

### 7) Governance and mobilization — 1–2 pages
**What it is:** How the portfolio will be governed and activated  
**What it includes:** PMO, workstreams, cadence, first 100 days, escalation  
**Typical formats:** governance chart; first-100-days plan; roadmap

## How to build
- define the value ambition and the gap to close
- organize the value levers into a clear theme set
- build the longlist of initiatives and design principles
- prioritize the portfolio using value and feasibility logic
- translate priority moves into initiative cards or charters
- build the value bridge and phasing
- set up governance, owners, and mobilization logic

## Success criteria
The portfolio is focused, the value bridge is credible, initiatives are distinct and actionable, and ownership and sequencing are visible.

## Common failure modes
Long initiative list with no choices; overlapping initiatives; no value logic; portfolio not linked to strategy; no phasing or owners; value double counted.
